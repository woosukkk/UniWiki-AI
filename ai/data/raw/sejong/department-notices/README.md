# 콘텐츠소프트웨어학과 공지 수집

콘텐츠소프트웨어학과(구 소프트웨어학과) 공식 공지 게시판에서 2024-01-01 이후 게시글을 조사한 결과다.

- 출처: https://dept.sejong.ac.kr/softwaredpt/board/notice.do
- 게시판 전체 게시물 수(확인 당시 표시값): 293건
- 2024년 이후 수집된 고유 게시물: 29건
- 확인일: 2026-07-31
- 게시판 최신 게시물 작성일: 2025-10-15

`all-notices-since-2024.json`은 제목·작성일·원문 URL을 보존한다. 지속적으로 참고할 가치가 있는 공학인증, AI 마이크로디그리, 연구실 안전교육, 학과 개편 자료만 위키 초기 데이터로 구조화한다. 채용·공모전·장학 모집처럼 접수기간이 끝난 공지는 역사 인덱스에는 남기되 현재 유효한 제도처럼 답변하지 않는다.

학생 이름이나 학번 일부가 표시된 안전교육 미이수자 명단은 수집하지 않았다.
