# 세종대학교 소프트웨어학과 교과과정

세종대학교 학사정보시스템의 `교과과정조회`에서 내려받은 원본 엑셀 파일이다.

- 조회 경로: 학부생학사정보 > 수업/성적 > 강좌조회 및 수강신청 > 교과과정조회
- 대상 학과: 소프트웨어학과(현 콘텐츠소프트웨어학과)
- 조회·수집일: 2026-07-31
- 포함 연도: 2024, 2025, 2026
- 포함 열: 학년, 개설년도, 개설학기, 교과목명, 이수구분, 학점/이론/실습
- 개인정보: 이름, 학번, 성적 등 개인 식별 정보 없음

교과과정은 해당 연도 교육과정이고 실제 학기별 개설 여부와 강의시간은 강의시간표 또는 학사정보시스템에서 별도로 확인해야 한다.
