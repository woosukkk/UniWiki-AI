# 세종대학교 강의시간표 원문

세종대학교 학사공지에서 내려받은 한국어·영어 강의시간표 원본이다.

- 범위: 2024학년도 1학기 ~ 2026학년도 2학기
- 기준일: 2026-07-31
- 한국어본 주요 열: 개설대학, 개설학과전공, 학수번호, 분반, 교과목명, 이수구분, 학년, 학점, 수업유형, 요일·시간, 강의실, 교수명, 주관학과, 수강 유의사항, 강의언어
- 시간, 강의실, 담당 교수, 추가 개설 및 폐강은 공지 이후 바뀔 수 있으므로 학사정보시스템을 최종 기준으로 삼는다.

원본에는 대학 전체 강좌가 포함된다. 소프트웨어학과는 2025학년도부터 콘텐츠소프트웨어학과로 개편되었으므로 두 학과명을 모두 고려해야 한다.
