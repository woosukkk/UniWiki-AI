# TOSC 공지

세종대학교 산학협력단 SW역량평가인증원의 공식 TOSC 공지 목록을 저장한다.

- 공식 사이트: https://tosc.sejong.ac.kr/
- 공지: https://tosc.sejong.ac.kr/ko/cusomter_support/notice
- 확인일: 2026-07-31
- 2024년 이후 수집 게시글: 18건

TOSC는 C 또는 Python을 선택해 응시하는 SW코딩역량평가다. 접수 회차, 시험일, 장소와 접수기간은 매회 공지를 확인한다. 세종대 학내 구성원은 학번 또는 사번으로 로그인하며, 시험 결과는 집현캠퍼스에서 확인한다.

콘텐츠소프트웨어학과를 포함한 SW 전공자의 졸업인증 기준은 TOSC 3급 이상 또는 `고급C프로그래밍및실습` B0 이상이다. 시험 운영 정보와 졸업인증 판정은 구분해 관리한다.
